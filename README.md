# Olá, eu sou o Antonio 👋

**Staff Software Engineer | AI Engineer** com mais de 18 anos de experiência na interseção entre arquitetura de sistemas em escala, plataforma cloud e produtos com IA aplicada.

Construí carreira em ambientes de missão crítica — incluindo mais de dois anos como Tech Lead / Software Architect no Itaú Unibanco, liderando arquitetura multi-cloud (AWS, GCP, Azure) para produtos de alto volume transacional, sob exigências de compliance regulatório (LGPD, PCI-DSS).

- 🔭 Atualmente na **Desrotulando**, atuando de ponta a ponta: construí o app (Flutter/Dart) e os backends (Go e Node.js), arquitetados sobre AWS e Firebase, além das pipelines de extração de dados multimodal com IA generativa (Gemini API) para reconhecimento de produtos. CI/CD com Codemagic, GitHub Actions e Azure Pipelines
- 🎓 MBA em Arquitetura de Soluções e MBA em Ciência de Dados e Inteligência Artificial (Universidade Anhanguera)
- 🌱 Aprofundando em engenharia de dados e otimização de custo/latência entre camadas de modelos de IA
- 💬 Fale comigo sobre arquitetura multi-cloud, IA generativa aplicada a produto, Flutter e engenharia mobile
- 📫 [contato@antoniodesouza.com.br](mailto:contato@antoniodesouza.com.br) · [antoniodesouza.com.br](https://www.antoniodesouza.com.br)
